# СВОИ · ДВОР — План внедрения маркетплейса услуг ЖК, Документы (152-ФЗ) и Студия Логотипа 1:1

Готовый интерактивный портал для запуска и продвижения Telegram-сервиса бытовых услуг между соседями жилых комплексов:
- **Атомарный план внедрения в ЖК** (6 пошаговых этапов с сохранением прогресса в браузере).
- **Скрипты первого контакта и ответы на возражения** (для админов домовых Telegram-чатов, председателей ТСЖ и УК).
- **Юридический пакет и 152-ФЗ** (Матрица ответственности сторон, Оферта информационного посредника по ст. 1253.1 ГК РФ, Правила сообщества ЖК с лимитами, Политика обработки данных 152-ФЗ, Паспорт пилота).
- **Студия квадратного логотипа 1:1** (4 концепта, 4 архитектурные палитры, модульная сетка золотого сечения $\varphi$, экспорт PNG до 4096×4096 и векторного SVG).

## Как включить автоматическую публикацию сайта на GitHub Pages

В проект уже встроен готовый воркфлоу `.github/workflows/deploy-pages.yml` и настроен относительный `base: './'` в `vite.config.ts`:

1. Нажмите на иконку **GitHub** (или **Export to GitHub**) в верхней панели интерфейса AI Studio и отправьте код в свой репозиторий на GitHub.
2. Откройте созданный репозиторий на сайте GitHub и перейдите во вкладку **Settings** $\rightarrow$ **Pages** (в левом меню).
3. В разделе **Build and deployment** $\rightarrow$ **Source** выберите **GitHub Actions**.
4. Через ~1 минуту во вкладке **Actions** завершится автоматическая сборка, и ваш сайт станет доступен онлайн по ссылке вида:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
